# قالب النسخ الاحتياطي اليومي (H3)

> ⚠ **لا تضع هذه الملفّات في `zid-sync` العامّ.** أرشيفات ريبو عامّ يقدر أيّ مستخدم GitHub تنزيلها ⇒ كشف بيانات عملك.
> انسخها إلى ريبو **خاصّ** جديد (مثلاً `zid-sync-backups`).

## الخطوات (مرّة واحدة)

### ١) أنشئ ريبو خاصّاً
GitHub → New repository → الاسم `zid-sync-backups` → **Private** ✅ → Create.
ثمّ ضع فيه: `backup.mjs` (كما هو) و`.github/workflows/backup.yml` (انسخ `backup.yml` هنا إلى هذا المسار) و`RESTORE.md`.

### ٢) أنشئ حساب «نسخ احتياطيّ» (viewer بلا دور)
Supabase → **Authentication → Users → Add user** → بريد (مثلاً `backup@…`) ＋ كلمة مرور قويّة → Create.
**🚫 لا تُدرجه في `user_roles`** — فيبقى موثّقاً **بلا دور**: `get_my_role()` يعيد `null`، و`null in ('owner','admin')` = مرفوض ⇒ **يقرأ كل شيء ولا يكتب شيئاً** (أقلّ امتياز؛ آمن لو تسرّبت بيانّاته). القراءة مسموحة لأن سياسات `select` مفتوحة للموثّقين.
**تحقّق من المنع:** سجّل دخوله وجرّب `POST /rest/v1/mappings` ⇒ يجب أن يُرفض (401/403 من RLS).

### ٣) أضِف الأسرار (في الريبو الخاصّ: Settings → Secrets and variables → Actions)
- `SUPABASE_URL` = `https://pfbcyxciqrttukayskkg.supabase.co`
- `SUPABASE_PUBLISHABLE_KEY` = مفتاح النشر (نفسه في الأداة — آمن)
- `BACKUP_EMAIL` = بريد حساب النسخ
- `BACKUP_PASSWORD` = كلمته

### ٤) شغّل يدويّاً أوّل مرّة
Actions → «نسخة Supabase الاحتياطية اليومية» → Run workflow. راجع السجلّ (أعداد الجداول) والأرشيف.

## الأجوبة (أسئلتك الثلاثة)
- **(أ) 7 أيام كافية؟ وهل يترك الحذف يوماً بلا نسخة؟** الاستبقاء **8 أيام** (لا 7) هامشُ أمان ⇒ لديك دائماً 7-8 نسخ. كل تشغيل يُنشئ أرشيفاً جديداً قبل أن يحذف GitHub ما تجاوز 8 أيام ⇒ **لا فجوة إطلاقاً**.
- **(ب) دور حساب viewer؟** **بلا دور في `user_roles`** (كما رجّحت) — RLS تمنع كتابته فعلاً (مثبت في الخطوة ٢). القراءة تكفي للنسخ.
- **(ج) 6-8MB/يوم × 7 داخل المجاني؟ gzip؟** نعم: **gzip** يضغط JSON ~5-8× (‏~6-8MB ⇒ ~1MB)، و8 نسخ ≈ 8MB — ضمن حدّ artifacts المجاني للخاصّ (500MB) بمساحة واسعة. ودقائق Actions (~2-4 د/يوم ≈ 90 د/شهر) ضمن 2000 د المجانية.

## لماذا artifacts في ريبو خاصّ لا commits؟
- **خاصّ:** أرشيفات الريبو الخاصّ لا يراها إلا المتعاونون (بيانات محميّة).
- **بلا تضخّم git:** الأرشيفات تنتهي تلقائياً (8 أيام) فلا يتضخّم تاريخ git بـ~7MB يومياً.
